# Sound credits

Every bundled clip is openly licensed. The rest of CART's built-in sounds (vine-boom-style thud, air horn, record scratch, sad trombone, cha-ching, choir, buzzer, whoosh, ticks) are synthesised in code in `src/content/sfx.js`, so there is no audio file behind them.

Clips were trimmed, converted to mono Ogg Vorbis and loudness-normalised for CART.
